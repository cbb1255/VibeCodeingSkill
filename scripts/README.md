# scripts/ 说明

放技能的**可执行辅助脚本**（`.py` / `.ps1` / `.sh` / `.js` 等），模型在需要时会运行它们。

## 放什么

- 需要确定性计算或和外部工具打交道的逻辑（解析、生成、转换、校验……）；
- 不适合塞进自然语言指令里的重复性操作。

## 约定

1. 每个脚本自解释：文件头写清楚「干什么、参数、返回什么」。
2. 零依赖优先；有依赖就在脚本头部注明安装命令。
3. 除 SKILL.md 明确授权外，脚本不要写文件、不要联网、不要动系统配置。
4. SKILL.md 正文必须写明**何时运行**：触发条件 + 完整命令行示例。

## 示例

`example.py` 是一个带参数解析的最小示范：在 SKILL.md 里引用它可以写成

```
python scripts/example.py --name <项目名>
```

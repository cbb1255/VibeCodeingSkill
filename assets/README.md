# assets/ 说明

放**静态资源**：输出模板、图片、样例数据、配置文件骨架等，模型按需读取，不执行。

## 放什么

- 输出模板：报告 / 邮件 / 邮件 / 文档的 `.md`、`.docx`、`.html` 模板；
- 图片：示意图、截图素材、logo；
- 样例数据：供演示或测试用的输入样例。

## 约定

1. 文件名自解释：`report-template.md`、`email-template.html`……
2. SKILL.md 正文里写清**怎么用**，例如：
   「以 `assets/report-template.md` 为骨架填充内容后输出。」
3. 模板中的变量用 `{{占位符}}` 标记，方便模型替换。
